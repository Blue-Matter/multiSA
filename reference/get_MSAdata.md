# Retrieve data object used to fit model

A convenient function to retrieve the data object used to fit the model.
The object is embedded in an environment within the RTMB object.

## Usage

``` r
get_MSAdata(MSAassess)
```

## Arguments

- MSAassess:

  [MSAassess](https://blue-matter.github.io/multiSA/reference/MSAassess-class.md)
  object returned by
  [`fit_MSA()`](https://blue-matter.github.io/multiSA/reference/fit_MSA.md)

## Value

[MSAdata](https://blue-matter.github.io/multiSA/reference/MSAdata-class.md)
object
